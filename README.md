Description

A simple command-line expense tracker application built with Node.js.
This project allows users to manage their daily expenses by adding, updating, deleting, and viewing expense records. The application also provides expense summaries, including total expenses and monthly summaries, and supports exporting data to a CSV file.

The project was created to practice CLI development, file system operations, and logic building using Node.js.

✨ Features

- Add a new expense with description and amount
- Update an existing expense
- Delete an expense by ID
- View all recorded expenses
- View total expense summary
- View monthly expense summary (current year)
- Export expenses to a CSV file
- Data stored locally using a JSON file

🛠️ Technologies Used

*Node.js
*Commander (CLI argument parsing)
*File System (fs/promises)
*JavaScript (ES Modules)
